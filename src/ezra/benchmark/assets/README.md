# Benchmark assets

`portrait.jpg` — photograph of astronaut Eileen Collins, NASA. Distributed by
scikit-image (`skimage.data.astronaut`), whose documentation states it was
downloaded from the NASA Great Images database and has "No known copyright
restrictions, released into the public domain". Resized to 384×384.

No speech or other media is committed. Fixture audio is synthesized at build
time with the machine's TTS engine (macOS voices are licensed for personal use,
so their output is never checked in).
